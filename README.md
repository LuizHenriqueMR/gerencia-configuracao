## Entrega 4 — Processo de Gerência de Configuração

O processo foi organizado em cinco tarefas distribuídas em duas releases.

### Responsabilidades

- **Gerente de Configuração:** organiza o controle de versão, as branches e o planejamento das releases.
- **Desenvolvedor:** prepara a estrutura do sistema web, implementa o script de construção e configura o GitHub Actions.
- **Responsável pela Qualidade:** verifica o funcionamento do processo de construção, revisa a documentação e valida os resultados.

### Como as tarefas estão interligadas

O processo começa com a configuração do controle de versão e a organização do repositório.

Em seguida, o desenvolvedor organiza os arquivos HTML e CSS do sistema web e prepara o script de construção.

Depois, o GitHub Actions é configurado para automatizar a construção do sistema.

Por último, o responsável pela qualidade verifica os resultados e a documentação. Caso encontre problemas, a tarefa retorna ao desenvolvedor para correção e nova validação.

### Organização das releases

**Release 1 — Estrutura inicial:** issues #1, #2 e #3.

**Release 2 — Melhorias e automação:** issues #4 e #5.

Cada issue possui um papel responsável identificado no GitHub Project, permitindo acompanhar as responsabilidades e a evolução do trabalho.
